# 发布说明

格式约定：每个版本一节，最新的在最上面。
面向用户的文案直接抄 GitHub Release 正文即可。

---

## Android 版签名信息

发布 APK 使用项目自签证书（非 debug 签名）：

| 项 | 值 |
|---|---|
| Keystore | `release-keystore.jks`（**不入库**，本地/CI secret 保存） |
| Alias | `kline-trainer` |
| 算法 | RSA 4096 / SHA384withRSA |
| 有效期 | 30 年 |

> ⚠️ **keystore 一旦丢失，后续版本将无法覆盖安装**（签名不一致会被系统拒绝）。
> 请务必离线备份 `release-keystore.jks` 与 `keystore.properties`。
>
> 证书 SHA-256 指纹可在安装后通过 `keytool -list -v` 核对。

### CI 如何签名

`.github/workflows/release.yml` 从仓库 Secrets 读取：

| Secret | 内容 |
|---|---|
| `KEYSTORE_BASE64` | `base64 -w0 release-keystore.jks` 的结果 |
| `KEYSTORE_PASSWORD` | keystore 口令 |
| `KEY_ALIAS` | `kline-trainer` |
| `KEY_PASSWORD` | key 口令 |

### 本地如何签名

在 `android/` 下创建 `keystore.properties`（已被 `.gitignore` 忽略）：

```properties
storeFile=release-keystore.jks
storePassword=你的口令
keyAlias=kline-trainer
keyPassword=你的口令
```

然后 `./gradlew :app:assembleRelease` 即产出已签名的 release APK。
若没配置，构建会打印警告并回退 debug 签名。
